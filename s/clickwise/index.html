Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http clickwise https://partners.clickwise.net/api/v1/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://partners.clickwise.net/api/v1/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "clickwise": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://partners.clickwise.net/api/v1/mcp"
      ]
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

{
  "mcpServers": {
    "clickwise": {
      "type": "http",
      "url": "https://partners.clickwise.net/api/v1/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

search_productscan modifySearch fresh GTIN products in the catalog your affiliate can deliver (freshness, permissions and caps apply). …

Search fresh GTIN products in the catalog your affiliate can deliver (freshness, permissions and caps apply). Requires your affiliate API key in X-API-Key or Bearer authorization; a sandbox key (cw_sbx_, free at partners.clickwise.net/developers) also works and returns example links that never earn. Every key gets exactly the REST GET /api/v1/publisher/products/ format (with gtin: /products/lookup/): products with id, gtin, title, price and currency, url (a Clickwise /dl/ tracked link created for your affiliate the first time a product is returned), image, merchant (id, name and its public website domain), availability, country, brand, category, regular_price, description, size, color and group_id (shared by the sizes of one model and colour), plus count, total and total_exact. Search by text, brand or category, or list one market by country alone; min_price and max_price filter by price in each product's own currency (inclusive, no conversion) and currency keeps one currency; with gtin every market carrying that GTIN is searched; offset paginates.

ParameterTypeDescription

currencystringoptionalISO 4217 code: only products priced in this currency (the price range then applies to it).
limitintegeroptional
offsetintegeroptional
