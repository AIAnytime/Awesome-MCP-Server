Openhook

Capture HTTP, email, and DNS callbacks and wait for or inspect inbox events through MCP; private inbox tokens control reads and deletion. MIT self-hosting and free temporary hosted inboxes are available, with optional paid persistent hosting.

Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http openhook https://openhook.dev/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://openhook.dev/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "openhook": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://openhook.dev/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "openhook": {
      "url": "https://openhook.dev/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "openhook": {
      "type": "http",
      "url": "https://openhook.dev/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "openhook", "type": "http", "url": "https://openhook.dev/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "openhook": {
      "serverUrl": "https://openhook.dev/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://openhook.dev/mcp
{
  "mcpServers": {
    "openhook": {
      "type": "http",
      "url": "https://openhook.dev/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.
