Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http agentoolrank https://agentoolrank.com/api/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://agentoolrank.com/api/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "agentoolrank": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://agentoolrank.com/api/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "agentoolrank": {
      "url": "https://agentoolrank.com/api/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "agentoolrank": {
      "type": "http",
      "url": "https://agentoolrank.com/api/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "agentoolrank", "type": "http", "url": "https://agentoolrank.com/api/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "agentoolrank": {
      "serverUrl": "https://agentoolrank.com/api/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://agentoolrank.com/api/mcp
{
  "mcpServers": {
    "agentoolrank": {
      "type": "http",
      "url": "https://agentoolrank.com/api/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

submit_tool[Tool directory] List an AI agent tool (framework, coding agent, MCP server, memory/RAG, evals, browser …

[Tool directory] List an AI agent tool (framework, coding agent, MCP server, memory/RAG, evals, browser agent...) on AgentoolRank for free.
