Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http proofsource https://app.proofsource.co/v1/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://app.proofsource.co/v1/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "proofsource": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://app.proofsource.co/v1/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "proofsource": {
      "url": "https://app.proofsource.co/v1/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "proofsource": {
      "type": "http",
      "url": "https://app.proofsource.co/v1/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "proofsource", "type": "http", "url": "https://app.proofsource.co/v1/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "proofsource": {
      "serverUrl": "https://app.proofsource.co/v1/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://app.proofsource.co/v1/mcp
{
  "mcpServers": {
    "proofsource": {
      "type": "http",
      "url": "https://app.proofsource.co/v1/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

add_brandcan modifyexternal accessStart measuring a brand: does ChatGPT, Perplexity, Claude or Google AI mention it, and who does AI recommend …

Start measuring a brand: does ChatGPT, Perplexity, Claude or Google AI mention it, and who does AI recommend instead? Give the brand's website (or its app store, Google Maps, YouTube or Instagram link). It reads the site, picks the buyer questions, and starts the first scan across the AI engines. Reading the site takes 1-2 minutes; if it is still running, call again with the same link and it picks up the same run, never a second one. Returns the brand_id; then use get_scan_status.

linkstringrequiredThe brand's website, like acme.com, or its app store, Google Maps, YouTube or Instagram link.
