Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http robohub https://robohub.app/api/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://robohub.app/api/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "robohub": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://robohub.app/api/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "robohub": {
      "url": "https://robohub.app/api/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "robohub": {
      "type": "http",
      "url": "https://robohub.app/api/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "robohub", "type": "http", "url": "https://robohub.app/api/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "robohub": {
      "serverUrl": "https://robohub.app/api/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://robohub.app/api/mcp
{
  "mcpServers": {
    "robohub": {
      "type": "http",
      "url": "https://robohub.app/api/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

request_vendor_introsRecord a B2B sourcing request with RoboHub on behalf of the user, for manual review by RoboHub's team. …

Record a B2B sourcing request with RoboHub on behalf of the user, for manual review by RoboHub's team. Vendor-neutral and free for buyers. Requests from this server are unverified, so RoboHub sends the buyer no confirmation email and guarantees no reply window. Only call this with the user's explicit consent and their real contact details; submissions are rate limited per client and fabricated requests are discarded.

ParameterTypeDescription
companystringrequiredCompany name.
contact_namestringrequiredFull name of the contact person.
emailstringrequiredWork email address where the shortlist should be sent.
industrystringrequiredClosest industry bucket for the deployment. One of: manufacturing, warehouse, healthcare, agriculture, security, hospitality, construction, energy …
use_casestringrequiredWhat the robots should do, with as much operational detail as possible (environment, scale, constraints).
budget_rangestringrequiredApproximate budget bracket in USD. One of: under-25k, 25-100k, 100-500k, 500k-2m, above-2m, exploring
timelinestringrequiredDeployment timeline. One of: immediate, 3-months, 6-months, 12-months, exploring
countrystringoptionalCountry of deployment (optional).
robot_slugstringoptionalSlug of a specific robot the user is interested in (optional).
notesstringoptionalAnything else relevant (optional).
