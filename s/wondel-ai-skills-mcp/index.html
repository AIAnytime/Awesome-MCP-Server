Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http wondel-ai-skills-mcp https://skills.wondel.ai/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://skills.wondel.ai/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "wondel-ai-skills-mcp": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://skills.wondel.ai/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{

    "wondel-ai-skills-mcp": {
      "url": "https://skills.wondel.ai/mcp"

  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

get_skillread-onlyMetadata for one skill or journey: its definition, when to use it, when not to, and related slugs. …

Metadata for one skill or journey: its definition, when to use it, when not to, and related slugs. Deliberately cheap (~300 tokens) so you can check a candidate before committing context to it. recommend_skillsread-onlyRoute a task to the right skills. Describe the job in your own words and this returns which skills to load …

Route a task to the right skills. Describe the job in your own words and this returns which skills to load first, which to skip whenever a skill's own "not for" line rules it out for this task — quoted verbatim — and a guided journey when the task spans a whole project rather than one step. search_skillsread-onlySearch 51 book-based agent skills and 14 guided journeys by keyword or phrase. Each skill is matched against …

Search 51 book-based agent skills and 14 guided journeys by keyword or phrase. Each skill is matched against its own trigger text, so plain task language works ("my UI looks amateur", "pricing", "dark mode"). Returns compact hits, each quoting the line that matched. Use recommend_skills instead when you have a task rather than a keyword.
