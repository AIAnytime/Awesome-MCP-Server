Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http nothumansearch https://nothumansearch.ai/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://nothumansearch.ai/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "nothumansearch": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://nothumansearch.ai/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "nothumansearch": {
      "url": "https://nothumansearch.ai/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "nothumansearch": {
      "type": "http",
      "url": "https://nothumansearch.ai/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "nothumansearch", "type": "http", "url": "https://nothumansearch.ai/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "nothumansearch": {
      "serverUrl": "https://nothumansearch.ai/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://nothumansearch.ai/mcp
{
  "mcpServers": {
    "nothumansearch": {
      "type": "http",
      "url": "https://nothumansearch.ai/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

handoff_provider_actionPresent the exact ticket bearer returned by prepare_provider_action. NHS records one privacy-safe handoff …

Present the exact ticket bearer returned by prepare_provider_action. NHS records one privacy-safe handoff receipt, then returns the attributed provider action URL. Optionally and separately, the principal may authorize the exact DNS-verified provider to resolve only the ticket's controlled topic, region, USD budget band, urgency, and allowlisted requirement flags. Declining that optional disclosure does not block the handoff. No query, contact detail, agent/principal identity, network address, referrer, or user-agent is disclosed. The handoff and resolver charge neither party; only the provider's configured downstream outcome can create a provider charge.

Record the caller's attestation that its human or company principal currently wants one controlled next step with a site returned organically by a receipt-bearing NHS discovery tool. This creates a private Stage 1 demand receipt that expires with the source discovery receipt, no later than 30 days after it. It does not contact the provider, create an action ticket or charge, change rank or score, or count as commercial proof. No query, contact data, free-form text, or agent/principal identity is accepted. Exact v1 wording: https://nothumansearch.ai/privacy#action-interest-v1

Submit a URL for NHS to crawl and score. Use when you discover an agent-first tool, API, or service that isn't in the index yet.
