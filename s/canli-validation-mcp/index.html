canli-validation-mcp

Checks whether a backtest result is real or just the luckiest of the variants tried: deflated Sharpe ratio, CSCV probability of backtest overfitting, data-snooping tests (Hansen's SPA, White's Reality Check, Romano-Wolf StepM), a lookahead check and a pipeline placebo test. Free, no API key; also runs locally with npx -y canli-validation-mcp. Endpoint: https://canlicapital.com/mcp · Docs · Registry: io.github.arhancanli/canli-validation-mcp

Prompts 8

  • validate_backtest Walk through the deflated Sharpe, overfitting and track-record checks for one strategy, and report what the numbers do not establish.
  • track_record_needed The minimum track record length for a Sharpe to clear a benchmark, with the record's own probabilistic Sharpe if its length is known.
  • backtest_and_validate Run a strategy family over a parameter grid on your prices, then read the deflated Sharpe and overfitting probability that count every variant run.
  • stress_my_strategy Resampled histories and named crash, volatility, repeat and outage scenarios for a strategy's returns.
  • production_check Order-rate and minimum-order limits, 2026 day-trading rules, market impact, crowding and capacity for a trading plan.
  • summarize_market_series Summarize a price or return file instead of reading its rows.
  • check_signal_for_lookahead Rerun your own signal code on prefixes the server picks, and find any value that depends on later rows.
  • test_pipeline_on_placebos Run your whole research pipeline on placebo data, where nothing can be predicted, and see whether its real result beats what it finds there.
