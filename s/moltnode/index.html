MoltNode by Chord

Read 31 blockchains over JSON-RPC (Ethereum, Base, Arbitrum, Solana, Monad, BNB Chain, Avalanche, Sui and more) and get DEX swap quotes with the unsigned transaction, approval and simulation via Chord. Hosted, no account or API key; non-custodial, the user's wallet signs. Endpoint: https://moltnode.ag/mcp · Docs · Registry: io.github.tuantqse90/moltnode

Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http moltnode https://moltnode.ag/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://moltnode.ag/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "moltnode": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://moltnode.ag/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "moltnode": {
      "url": "https://moltnode.ag/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "moltnode": {
      "type": "http",
      "url": "https://moltnode.ag/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "moltnode", "type": "http", "url": "https://moltnode.ag/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "moltnode": {
      "serverUrl": "https://moltnode.ag/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://moltnode.ag/mcp
{
  "mcpServers": {
    "moltnode": {
      "type": "http",
      "url": "https://moltnode.ag/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.

chord_swap_quoteread-onlyexternal accessBest swap route from Chord (getchord.xyz) across the DEXs of the chain, with the UNSIGNED transaction to …

Best swap route from Chord (getchord.xyz) across the DEXs of the chain, with the UNSIGNED transaction to sign, the ERC-20 approval it needs (as a ready transaction) and a simulation run from the taker wallet. Amounts are integer strings in the token's smallest unit; the zero address is the native coin. Nothing is sent: sign with your own key, then send_raw_transaction.

ParameterTypeDescription
chainstringrequiredChord chain key. One of: base, ethereum, monad, bnb, avalanche, arbitrum, robinhood, arc
tokenInstringrequiredToken sold (zero address = native coin).
tokenOutstringrequiredToken bought (zero address = native coin).
amountstringrequiredAmount of tokenIn in its smallest unit, e.g. '10000000' = 10 USDC.
takerstringoptionalThe wallet that will sign. With it the answer carries tx + approval + a simulation from that wallet.
slippageBpsintegeroptionalSlippage in basis points (default 50).

Example call (required arguments only, placeholder values):

{
  "method": "tools/call",
  "params": {
    "name": "chord_swap_quote",
    "arguments": {
      "chain": "base",
      "tokenIn": "...",
      "tokenOut": "...",
      "amount": "..."
    }
  }
}
