Chord

DEX swap quotes and unsigned swap transactions on 7 EVM chains (Base, Monad, BNB Chain, Avalanche, Arbitrum, Robinhood Chain, Arc), plus token boards, candles, trades, wallet PnL, smart money, holders and LP pools (Solana data read-only). Hosted, no key for data and swaps (about 60 requests a minute), only chord_ask needs an API key; non-custodial. Endpoint: https://api.getchord.xyz/v1/mcp · Docs · Registry: io.github.getchordlabs/chord

Set up in your client

Claude Code

Run this in a terminal:

claude mcp add --transport http chord https://api.getchord.xyz/v1/mcp

Claude Desktop

Open Settings → Connectors → Add custom connector and paste this URL:

https://api.getchord.xyz/v1/mcp

Or bridge it through mcp-remote in claude_desktop_config.json (needs Node.js):

{
  "mcpServers": {
    "chord": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://api.getchord.xyz/v1/mcp"
      ]
    }
  }
}

Cursor

Add to Cursor

Or add it to ~/.cursor/mcp.json (or .cursor/mcp.json in a project):

{
  "mcpServers": {
    "chord": {
      "url": "https://api.getchord.xyz/v1/mcp"
    }
  }
}

VS Code

Add to VS Code

Or add it to .vscode/mcp.json:

{
  "servers": {
    "chord": {
      "type": "http",
      "url": "https://api.getchord.xyz/v1/mcp"
    }
  }
}

Or from a terminal:

code --add-mcp '{"name": "chord", "type": "http", "url": "https://api.getchord.xyz/v1/mcp"}'

Windsurf

Add it to ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "chord": {
      "serverUrl": "https://api.getchord.xyz/v1/mcp"
    }
  }
}

Other clients

Most clients accept this shape. The endpoint is:

https://api.getchord.xyz/v1/mcp
{
  "mcpServers": {
    "chord": {
      "type": "http",
      "url": "https://api.getchord.xyz/v1/mcp"
    }
  }
}

If it does not connect

  • Restart the client after editing a config file, and keep keys out of files you commit.
  • If the tools do not appear, open the client's MCP log: a 401 means the credentials were not accepted, and a timeout means the server did not answer.
